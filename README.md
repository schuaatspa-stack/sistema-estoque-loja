# Sistema de Estoque para Loja

Sistema de controle de estoque via terminal, pensado para uso real em pequenas lojas de materiais de construção/encartelados.

## Funcionalidades
- Cadastro de produtos (nome, preço, quantidade)
- Consulta de estoque atual
- Registro de vendas (carrinho de compras com múltiplos itens)
- Registro de entrada de mercadoria (reposição de estoque)

## Tecnologias
- Python 3.14

## Como executar
```bash
python estoque.py
```
